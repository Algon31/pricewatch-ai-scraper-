# WebPulse — Frontend Dashboard

React 19 + Vite + Tailwind CSS v4 competitor monitoring dashboard for **WebPulse**.

For full project documentation, architecture diagrams, setup instructions, and API references, please see the [Root README](../README.md).

## Quick Start

```bash
# Install dependencies
npm install

# Start Vite development server
npm run dev
# Launches at http://localhost:5173
```

## Available Scripts

- `npm run dev`: Launch Vite local development server with hot module reloading.
- `npm run build`: Build production assets into `dist/`.
- `npm run preview`: Preview the production build locally.
